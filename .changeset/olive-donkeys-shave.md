Add Changesets-based versioning and an auto-updating workflow diagram.

The README now opens with a Mermaid diagram of how the pack fits together — entry point, always-loaded instruction files, the delivery stages from `AI_ENGINEERING_WORKFLOW.md`, the external-contribution track, and the guardrail skills. It is generated by `scripts/generate-workflow-diagram.mjs` from the skills actually on disk, checked for drift in CI, and regenerated as part of every version bump, so it cannot fall behind the pack.

Release intent is now recorded in `.changeset/` instead of by hand. Nothing is published to a registry: the install path stays `npx skills add wakqasahmed/ai-engineering-workflow-skills`, and Changesets owns only the version number and the changelog.
