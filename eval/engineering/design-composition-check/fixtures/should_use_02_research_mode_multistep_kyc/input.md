# Scenario

A design system was derived from a competitor-research mode pass (screenshots
of other products, no source file) for a fintech onboarding product.
Non-technical stakeholders need to sign off on it. Three features are queued:

- A static "Why verify your identity" explainer screen.
- A primary multi-step KYC flow: document upload → liveness check → manual
  review → approved/declined, each with its own retry and error states.
- An audit log screen listing every verification attempt with faceted search.

No screen has been built against this system yet.
